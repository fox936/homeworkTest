## 🎯 一、作业目标

上一次你已经会用 `if / else if / else` 写多分支了。但分支多起来时，`if` 会变得又长又难读——C 语言为此提供了 **`switch` 语句**。本次作业要让你掌握：

| 序号 | 能力目标 |
|:---:|:---|
| 1 | 掌握 `switch / case / break / default` 的完整语法 |
| 2 | 理解 **`break` 的作用**，以及漏写 `break` 会发生什么（穿透） |
| 3 | 会利用**多个 `case` 合并**来简化代码 |
| 4 | 知道 `switch` 能做什么、**不能**做什么，并能在 `if` 和 `switch` 之间做出正确选择 |
| 5 | 把 `switch` 与 `if` 配合使用，解决"月份天数""成绩等级"这类实际问题 |

> 💡 本次仍然**不需要**循环（`for`/`while`）、数组、自定义函数。所有程序都只有 `main` 一个函数。

## ⚠️ 四、动手前必须知道的五件事

### ① `break` 是 `switch` 的灵魂

```c
switch (n) {
case 1:
    printf("一\n");
    break;          /* ← 没有它，会继续往下执行 case 2 */
case 2:
    printf("二\n");
    break;
default:
    printf("其他\n");
}
```

**漏写 `break` 不会报错**，程序照样编译通过，但会"掉"到下一个 `case` 里去执行——这叫**穿透（fall-through）**，是初学者最常见的 bug。

> 验证方法：把某个 `break` 删掉，观察输出会多打印什么。

### ② `switch` 的括号里**只能是整数或字符**

```c
switch (score / 10) { ... }   /* ✅ 整数表达式 */
switch (op) { ... }           /* ✅ char 也是整数类型 */
switch (price) { ... }        /* ❌ float / double 不行 */
switch (name) { ... }         /* ❌ 字符串不行 */
```

### ③ `case` 后面**必须是常量**，不能是变量或范围

```c
case 1:            /* ✅ */
case 'A':          /* ✅ */
case x:            /* ❌ 变量不行 */
case 1 ... 5:      /* ❌ C 语言不支持范围（那是别的语言） */
```

所以"90~100 分"这种范围**不能直接写成 `case 90...100`**，要用整数除法把它变成离散值（见题目2）。

### ④ `case` 可以合并，这正是 `switch` 的便利之处

```c
case 1: case 3: case 5: case 7: case 8: case 10: case 12:
    printf("31 天\n");
    break;
```

**故意合并时不要写 `break`**，让它们自然"穿透"到同一段代码——这种情况下穿透是**有意为之**，建议加一行注释说明。

### ⑤ `if` 还是 `switch`？看"判断依据"是什么

| 场景 | 推荐 | 原因 |
|:---|:---:|:---|
| 判断**一个变量等于几个固定值**之一（菜单、运算符、月份） | **`switch`** | 结构清晰，一眼看出所有分支 |
| 判断**范围**（`score >= 90`、`x > y`） | **`if`** | `switch` 只能比相等 |
| 判断**多个条件组合**（`a > 0 && b > 0`） | **`if`** | `switch` 表达不了 |
| 判断 `double` / 字符串 | **`if`** | `switch` 不支持 |

题目2 就是典型的"范围 → 用整数除法变成离散值 → 才能用 `switch`"。

### 🍽️ 题目1（必做）· 菜单选择

**文件：`task1_menu.c`**

先打印一个菜单，再读入用户的选择，用 `switch` 输出对应的说明。

**先输出菜单：**

```text
===== 学生成绩管理系统 =====
  1. 录入成绩
  2. 查询成绩
  3. 修改成绩
  4. 退出系统
============================
请输入你的选择：
```

**读入一个整数后，用 `switch` 分派：**

| 输入 | 输出 |
|:---:|:---|
| 1 | `你选择了：录入成绩` |
| 2 | `你选择了：查询成绩` |
| 3 | `你选择了：修改成绩` |
| 4 | `你选择了：退出系统` |
| 其他 | `输入错误：请输入 1~4 之间的数字。` |

**要求：**

1. 用 `switch` 实现，每个 `case` 后都要有 `break`；
2. 非法输入由 `default` 处理；
3. 菜单要完整打印出来（对齐整齐即可，不强制逐列对齐）。

> 💡 提示：这就是 `switch` 最典型的用法——一个变量对应几个固定的取值。

### 🏅 题目2（必做）· 用 `switch` 重写成绩等级

**文件：`task2_grade.c`**

读入一个整数分数（0~100），输出等级：

| 分数区间 | 等级 |
|:---|:---:|
| 90 ~ 100 | A |
| 80 ~ 89 | B |
| 70 ~ 79 | C |
| 60 ~ 69 | D |
| 0 ~ 59 | E |

### ⚠️ 关键：上一次用 `if`，这一次必须用 `switch`

`switch` 不能直接写范围，但可以用**整数除法**把范围变成离散值：

```c
switch (score / 10) {
case 10:          /* 100 分 */
case 9:           /* 90~99 */
    printf("A\n");
    break;
case 8:           /* 80~89 */
    ...
}
```

**要求：**

1. 必须先判断分数是否合法（`< 0` 或 `> 100`），非法时输出 `输入错误：分数应在 0~100 之间。`，**不要**再输出等级；
2. **必须用 `switch`**，不能用 `if-else if` 链；
3. 空输入的边界（0 分、100 分）都要正确。

**运行示例：**

```text
请输入分数：95
分数 95，等级：A
```

```text
请输入分数：100
分数 100，等级：A
```

```text
请输入分数：-3
输入错误：分数应在 0~100 之间。
```

> 💡 提示：`95 / 10` 的结果是 `9`（整数除法，小数部分丢弃），这就是把范围变成离散值的关键。

### 🧮 题目3（必做）· 简易计算器

**文件：`task3_calc.c`**

读入**两个整数**和**一个运算符**，用 `switch` 按运算符分派计算。

**输入格式**：`数字 运算符 数字`，例如 `12 + 5`

| 运算符 | 输出 |
|:---:|:---|
| `+` | `12 + 5 = 17` |
| `-` | `12 - 5 = 7` |
| `*` | `12 * 5 = 60` |
| `/` | `12 / 5 = 2`（整数除法） |
| 其他 | `输入错误：不支持的运算符。` |

**要求：**

1. 用 `switch (op)` 分派，`case` 里写字符常量：`case '+':`；
2. **除数为 0 时要提示**，不能崩：
   ```text
   12 / 0  ->  输入错误：除数不能为 0。
   ```
3. 运算符非法时由 `default` 处理，**不要**输出结果行。

**运行示例：**

```text
请输入算式（如 12 + 5）：12 * 5
12 * 5 = 60
```

```text
请输入算式（如 12 + 5）：12 / 0
输入错误：除数不能为 0。
```

> 💡 提示：用 `scanf("%d %c %d", &a, &op, &b)` 读取。`%c` 前面有一个空格，是为了跳过数字后面的空白。

### 📅 题目4（必做）· 年月天数

**文件：`task4_days.c`**

读入**年份**和**月份**，输出该月有多少天。

**要求：**

1. **用 `switch (month)`**，并利用**多个 `case` 合并**：
   ```c
   case 1: case 3: case 5: case 7: case 8: case 10: case 12:
       days = 31;
       break;
   ```
2. **2 月要根据年份判断**：闰年 29 天，平年 28 天（闰年规则：能被 4 整除且不能被 100 整除，或能被 400 整除）；
3. 月份不在 1~12 时输出 `输入错误：月份应在 1~12 之间。`。

**运行示例：**

```text
请输入年份和月份：2024 2
2024 年 2 月有 29 天。
```

```text
请输入年份和月份：1900 2
1900 年 2 月有 28 天。
```

```text
请输入年份和月份：2023 4
2023 年 4 月有 30 天。
```

```text
请输入年份和月份：2023 13
输入错误：月份应在 1~12 之间。
```

> 💡 提示：这一题是 `switch` 与 `if` 的**配合**——月份用 `switch`，闰年判断用 `if`。不用循环也能做。

### ⭐ 题目5（选做·加分）· 字符分类

**文件：`task5_char.c`**

读入**一个字符**，判断它属于哪一类：

| 类别 | 说明 | 输出示例 |
|:---|:---|:---|
| 元音 | `a e i o u` 及其大写 | `'a' 是元音字母。` |
| 辅音 | 其他字母 | `'b' 是辅音字母。` |
| 数字 | `0`~`9` | `'7' 是数字字符。` |
| 其他 | 其余字符 | `'#' 是其他字符。` |

**要求：**

1. **必须用 `switch`**；
2. 元音的 10 个字符（大小写各 5 个）用**多个 `case` 合并**处理；
3. 数字、其他字符用 `default` 或分组处理。

**运行示例：**

```text
请输入一个字符：a
'a' 是元音字母。
```

```text
请输入一个字符：B
'B' 是辅音字母。
```

```text
请输入一个字符：7
'7' 是数字字符。
```

> 💡 提示：`switch (ch)` 里，`char` 会当作整数比较，所以 `case 'a':` 是合法的。
> 判断"是字母"可以用 `(ch >= 'a' && ch <= 'z')`。
