## 🎯 一、作业目标

第一次作业的程序都是"写好什么就输出什么"，**数据是固定的**。本次作业要让程序**能接收你输入的数据**，并根据数据**做出判断**。完成后你应当能够：

| 序号 | 能力目标 |
|:---:|:---|
| 1 | 用 `scanf` 从键盘读取 `int`、`double`、`char` 三种类型的数据 |
| 2 | 掌握 `scanf` 与 `printf` 的**格式符对应关系**（尤其 `%f` 与 `%lf` 的区别） |
| 3 | 会用 `if`、`if-else`、`if-else if-else` 三种分支结构 |
| 4 | 会用关系运算符（`>` `<` `>=` `<=` `==` `!=`）和逻辑运算符（`&&` `\|\|` `!`） |
| 5 | 能处理**边界情况**：除数为 0、成绩越界、两数相等…… |
| 6 | 养成"每个输入都验证一遍"的编程习惯 |

> 💡 本次仍然**不需要**循环（`for`/`while`）、数组、自定义函数。所有程序都只有 `main` 一个函数。

## ⚠️ 四、动手前的五个坑（务必先看）

这次作业的错误大多集中在下面五处，**先看一遍能省很多调试时间**。

### 坑 1：`scanf` 必须传地址

```c
int age;
scanf("%d", age);    // ❌ 错：少了 &，程序会崩溃
scanf("%d", &age);   // ✅ 对
```

### 坑 2：`printf` 与 `scanf` 对 `float`/`double` 的要求不同

| 类型 | `printf` | `scanf` |
|:---|:---:|:---:|
| `float` | `%f` | `%f` |
| `double` | `%f` 或 `%lf`（等价） | **必须 `%lf`** |

> `scanf` 里用 `%f` 读 `double` 变量是**未定义行为**，会读错数据。请记住：**`scanf` 读 `double` 一律写 `%lf`**。

### 坑 3：读 `char` 前要加一个空格

```c
int age;
char blood;
scanf("%d", &age);
scanf("%c", &blood);     // ❌ 会读到你按下的回车符 '\n'
scanf(" %c", &blood);    // ✅ 格式串里 %c 前加一个空格，跳过空白字符
```

### 坑 4：判断相等用 `==`，不是 `=`

```c
if (a = 0)    // ❌ 这是赋值，结果恒为"假"
if (a == 0)   // ✅ 这才是判断
```

> 好消息：只要用 `gcc -Wall` 编译，编译器会对此发出警告。**这也是为什么作业要求"零警告"。**

### 坑 5：多分支用 `else if`，不要写成一串独立的 `if`

```c
if (score >= 90) printf("A\n");
if (score >= 80) printf("B\n");   // ❌ 95 分会同时输出 A 和 B
```

正确写法见题目4。

## 🧩 五、题目

### 📇 题目1（必做）· 个人信息录入

**文件：`task1_input.c`**

用 `scanf` 从键盘读入 **3 个**数据，再用 `printf` 输出一张信息卡。

| 读入内容 | 类型 | 提示语 |
|:---|:---|:---|
| 年龄 | `int` | `请输入年龄：` |
| 身高（米） | `double` | `请输入身高(米)：` |
| 血型 | `char` | `请输入血型：` |

**输出要求：**

1. 用闭合边框输出（`+----+` 与 `|`），**至少 5 行**；
2. 身高**保留 2 位小数**（用 `%.2f`）；
3. 三项数据都要在卡片里体现。

> 📌 **关于对齐**：一个汉字占 **2 个显示列**、却占 **3 个字节**，而 `printf` 的域宽按**字节**计算，所以卡片各行右竖线相差 1~2 列是**正常现象**。
> **本次不强制逐列对齐**（那是 Homework1 的重点，这次不重复扣分），只要边框闭合、每行都以 `|` 开头和结尾即可。

**运行示例：**

```text
请输入年龄：19
请输入身高(米)：1.75
请输入血型：A

+------------------------------+
|         个 人 信 息 卡       |
+------------------------------+
|  年龄：19 岁                 |
|  身高：1.75 米               |
|  血型：A 型                  |
+------------------------------+
```

> 💡 提示：这就是**坑 3** 的实战场景。如果血型读出来是空的或者怪字符，回去看坑 3。

### 🧮 题目2（必做）· 四则运算（含除零判断）

**文件：`task2_calc.c`**

读入**两个整数** `a` 和 `b`，然后输出：

| 输出项 | 说明 |
|:---|:---|
| 和 | `a + b` |
| 差 | `a - b` |
| 积 | `a * b` |
| 商 | `a / b`（整数除法） |
| 余数 | `a % b` |

**关键要求：必须先判断 `b` 是否为 0。**

- 若 `b` 为 0：只输出和、差、积，并输出一行 `除数不能为 0，无法计算商和余数。`
- 若 `b` 不为 0：五项全部输出。

**运行示例（b 不为 0）：**

```text
请输入两个整数：17 5
和   = 22
差   = 12
积   = 85
商   = 3
余数 = 2
```

**运行示例（b 为 0）：**

```text
请输入两个整数：17 0
和   = 17
差   = 17
积   = 0
除数不能为 0，无法计算商和余数。
```

> 💡 提示：`17 / 5` 在 C 语言里结果是 `3`（整数除法，直接截断），不是 `3.4`。这正是本题要你观察的现象。

### ⚖️ 题目3（必做）· 奇偶与大小判断

**文件：`task3_judge.c`**

本题目包含**两个小问**，写在同一个 `main` 里，分两次读入即可。

**(1) 判断奇偶**

读入一个整数 `n`，输出它是奇数还是偶数。

```text
请输入一个整数：7
7 是奇数。
```

**(2) 比较大小**

读入两个整数 `x`、`y`，输出较大的那个；若相等则输出提示。

```text
请输入两个整数：12 8
较大的数是：12
```

```text
请输入两个整数：5 5
两个数相等。
```

> 💡 提示：第 (1) 问用 `n % 2 == 0` 判断偶数；第 (2) 问需要 `if / else if / else` 三种情况。

### 🏅 题目4（必做）· 成绩等级

**文件：`task4_grade.c`**

读入一个整数分数（0~100），输出对应等级：

| 分数区间 | 等级 |
|:---|:---:|
| 90 ~ 100 | A |
| 80 ~ 89 | B |
| 70 ~ 79 | C |
| 60 ~ 69 | D |
| 0 ~ 59 | E |

**关键要求：**

1. **必须先判断分数是否合法**（`< 0` 或 `> 100`），非法时输出 `输入错误：分数应在 0~100 之间。`，**不要**再输出等级；
2. 必须用 `if / else if / ... / else` 的**多分支**结构，不能写成一串独立 `if`（见**坑 5**）；
3. 输出格式：`分数 95，等级：A`

**运行示例：**

```text
请输入分数：95
分数 95，等级：A
```

```text
请输入分数：-3
输入错误：分数应在 0~100 之间。
```

> 💡 提示：注意 `90~100` 这个区间的**上边界**——`score >= 90` 就够了，因为前面已经把 `> 100` 排除掉了。

### ⭐ 题目5（选做·加分）· 闰年判断

**文件：`task5_leap.c`**

读入一个年份，判断它是不是闰年。

**闰年规则：**

- 能被 4 整除，**且**不能被 100 整除 → 是闰年
- **或者**能被 400 整除 → 是闰年

**要求：**

1. 用 `&&` 和 `\|\|` 把上面的规则写成一个条件；
2. 输出形如 `2024 是闰年。` 或 `1900 不是闰年。`

**运行示例：**

```text
请输入年份：2024
2024 是闰年。
```

```text
请输入年份：1900
1900 不是闰年。
```

**测试数据（请自行验证这几组都对）：**

| 年份 | 是否闰年 | 原因 |
|:---:|:---:|:---|
| 2024 | 是 | 能被 4 整除，不能被 100 整除 |
| 1900 | 否 | 能被 100 整除，但不能被 400 整除 |
| 2000 | 是 | 能被 400 整除 |
| 2023 | 否 | 不能被 4 整除 |

> 💡 提示：条件写成 `(year % 4 == 0 && year % 100 != 0) || (year % 400 == 0)`。
